# Team Forge: 4-Way Autonomous Zero-Conflict Workflow Guide

This guide details the automated 4-way synchronization architecture powering **Team Forge (ForgeDiagnostics)** across **Android Studio**, **Antigravity IDE**, **Google AI Studio**, and **GitHub**.

## ⚡ Key Automation Features

1. **Real-Time File-Watcher & Debouncing (Local Changes)**:
   - File changes made in **Android Studio** or **Antigravity IDE** are detected within milliseconds.
   - Smart 3-second debouncing prevents fragmented commits during multi-file saves or builds.
   - Automatically commits with structured timestamped metadata and pushes to GitHub.

2. **Zero-Conflict Auto-Stash & Auto-Rebase (Incoming Remote Changes)**:
   - Polls GitHub every 10 seconds for commits generated by GitHub Actions (e.g. `Forge Autonomous Guardian`), PR merges, or web edits.
   - Uses `git pull --rebase --autostash` to merge changes without creating merge commits or clobbering in-progress local work.
   - Built-in **Auto-Healer** resolves concurrent race conditions and non-fast-forward collisions gracefully.

3. **Dual-Layer Git Hooks**:
   - `post-commit` hook triggers immediate background push whenever manual commits are made via Android Studio Git UI or VSCode.
   - `post-merge` hook logs synchronization state.

4. **Environment & Secrets Integration**:
   - `local.properties`: Auto-configures local Android SDK path (`C:\Users\<user>\AppData\Local\Android\Sdk`) and signing keys.
   - `.env`: Holds `GEMINI_API_KEY` for Android Studio `BuildConfig` and Antigravity tooling.
   - `npm run connect`: Automatically synchronizes `GEMINI_API_KEY` between local `.env` and GitHub Actions Secrets via `gh secret set`.

## 🛠️ CLI Commands & Utilities

| Command | Action |
| :--- | :--- |
| `npm run sync:watch` | Starts the live foreground sync watcher with real-time logs. |
| `npm run sync:silent` | Launches the background sync daemon silently on Windows (no console window). |
| `npm run sync` | Runs a single immediate 2-way sync cycle. |
| `npm run sync:status` | Displays git status and latest commit history. |
| `npm run connect` | Interactive 4-way setup & AI Studio key synchronizer. |
